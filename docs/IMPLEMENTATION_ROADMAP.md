# 麻将游戏分阶段实现计划

## 页面流程

`主页/房间配置 → 等待房间 → 牌局 → 单局结算 → 下一轮 → 总结算/好友积分榜`

## 阶段 1：可交互流程与统一 UI（已完成）

- 使用 `DemoSession` 作为 MVC Model 的内存实现。
- 主页创建/加入好友房，选择玩法、轮次、倍率与封顶。
- 等待房显示四个席位、准备状态、人数进度和开局条件。
- 牌局支持动态手牌、选牌、出牌、摸牌、碰/杠/过反馈与胡牌。
- 结算页根据实际本局分数渲染，并更新本房与好友累计排名。

## 阶段 2：局域网好友房

- 在 `infrastructure.network.server` 实现房主内置 TCP 服务。
- 在 `infrastructure.network.client` 实现客户端连接、心跳与自动重连。
- 使用 `FriendRoomService` 替换 `DemoSession` 的房间操作。
- 服务端广播 `RoomSnapshot`，实现多电脑席位与准备状态实时同步。

## 阶段 3：服务端权威牌局（核心已完成）

- 已实现 136 张牌墙、发牌、轮转、吃碰杠胡合法性校验。
- 已实现 `InMemoryGameSessionService`：客户端只发送 `ActionRequest`，服务端返回带 revision 的 `GameSnapshot`。
- 已实现胡牌响应优先级、过期 revision 拒绝、牌墙耗尽流局。
- 处理响应窗口、超时自动过、断线托管和重连恢复。

## 阶段 4：规则与计分（通用部分已完成）

- 已实现标准胡/七对判断及七对、清一色、混一色、碰碰胡基础牌型分析。
- 已实现服务端 `Settlement`、零和计分、基础倍率和封顶。
- 待分别追加四川、长沙、北方、红中麻将的特殊番型和限制。
- 将好友积分持久化到本地 SQLite/JSON 存储。

## 阶段 5：测试与发布

- 为规则引擎、房间状态机、协议编解码编写单元测试。
- 增加多客户端集成测试和断线重连测试。
- 使用 jlink/jpackage 生成 Windows 可运行包。
