# JavaFX 麻将游戏接口骨架

当前工程包含可编译的 MVC 接口骨架，以及“创建/加入好友房 → 等待入房 → 好友牌局 → 单局结算 → 下一轮/累计排名”的 JavaFX 可交互 Demo。

- 接口源码：`src/main/java/com/campus/mahjong/api/`
- 结构说明：`docs/INTERFACE_DESIGN.md`
- MVC 包结构：`docs/MVC_PACKAGE_STRUCTURE.md`
- 分阶段实现计划：`docs/IMPLEMENTATION_ROADMAP.md`
- 地区规则口径：`docs/REGIONAL_RULES.md`
- SQLite 数据设计：`docs/SQLITE_SCHEMA.md`
- 机器人老师与 Mock/RAG 接口：`docs/TEACHER_MOCK_API.md`
- 编译验证：`mvn compile`
- 启动主页面：`mvn javafx:run`

## 热点联机试运行

1. 房主电脑开启 Wi-Fi 热点，四台电脑都连接到该热点。
2. 四台电脑分别运行 `mvn javafx:run`。
3. 房主点击“创建好友房”，首次启动监听时允许 Java 通过系统防火墙。
4. 房主在等待页复制 `房主IP:19090#房间码` 格式的完整邀请地址。
5. 另外三名玩家在首页粘贴完整邀请地址并加入、准备。
6. 四人全部在线且准备后，房主点击开始；四端会进入同一个服务端权威牌局。

服务端默认监听 TCP `19090`。如果自动识别到的不是热点网卡地址，可以通过 JVM 参数显式指定：

```bash
mvn -Dmahjong.hostAddress=192.168.137.1 javafx:run
```

当前所有玩法采用血战到底的轮次流程：胡牌者退出本轮操作，其余玩家继续；三家胡牌或牌墙耗尽后，服务端自动发下一轮。全部设定轮次结束后，四端进入总排名与逐笔流水页面。已胡玩家不再承担后续自摸付款；同一弃牌允许多家胡牌。

本房底分为 10，平胡 0 番，每番翻倍。每位付款者支付 `min(10 × 房间倍率 × 2^番数, 房间封顶)`；点炮者向每位胡牌者各付一份，自摸由其余未胡玩家各付一份。完整番表见 `docs/REGIONAL_RULES.md`，牌桌右上角“番型计分”可随时查看。组合牌型按总番数计分，流水同时记录牌型与番数。

胡牌张在该玩家信息下方公开保留至本轮结束。每次胡牌，赢家显示绿色 `+积分`，付款者显示红色 `-积分`，持续 1 秒；同一弃牌多家胡牌时显示各家的净变化。联机胡牌事件由房主广播，重复快照不会重复播放，提示结束后再展示下一轮或最终结算。记牌面板会扣除其他玩家公开的自摸胡牌张。

流水包含轮次、付款方、收款方、胡牌方式、牌型和积分，结算页将每轮积分及流水幂等保存到本机 SQLite。当前未另加杠牌计分、查叫或退税规则。

联机协议已更新至版本 7，参与同一房间的客户端应使用同一新版。首页新增“开始教学”：自动安排三位老师陪练一轮，操作前给建议，主动出牌后给本人点评。普通等待房也可添加机器人老师，每次老师出牌后显示依据及规则引用。牌桌“文字讲解”开关可隐藏讲解，不影响打牌。讲解底层为本地 Mock，不需要密钥，也不调用外部 API。碰杠胡响应 10 秒超时后保留已提交选择、其他玩家自动过；断线令牌恢复仍未实现。教学模式及含机器人的练习场不计入好友长期积分。

## 对局操作与记牌

对局右下角的“记牌”可展开淡黄色不透明面板，按牌面显示未见张数：每种牌的总数扣除自己的手牌（含摸牌）、四家弃牌和碰杠区牌。数字包含对手暗手与牌墙中的牌，并非牌墙的精确余量；随牌局和轮次自动刷新。碰杠等操作按钮位于手牌上方的固定高度操作行，显隐不会改变手牌纵向位置。

## 四川麻将换三张

每轮流程为：发牌 → 换三张（15 秒）→ 定缺（10 秒）→ 庄家出牌。换牌只在四川模式启用。

四家各选恰好三张同花色的万、筒或条，可以包含重复牌，但不能超过实际持牌数量。庄家第十四张也可参与。点击选中牌可取消；确认后锁定，其他玩家只能看到是否确认。四家完成后，服务器统一随机决定顺时针、逆时针或对家交换，先收齐四家原始牌，再同时分发；每家仅看到自己收到的三张，随后开始定缺。

15 秒未确认者由服务器自动选择：在至少有三张的花色中选张数最少的一门，同数按万、筒、条顺序，再按点数从小到大取三张；已确认的选择保持不变。时长和超时策略属于本项目约定。

规则依据：[游戏茶苑换三张说明](https://www.gametea.com/news/201809/7450.html)、[血战到底流程说明](https://doublewin.me/guides/mahjong-xuezhandaodi)。各平台掷骰、方向决定方式存在变体，本项目采用服务器等概率随机三种方向。

## 四川麻将定缺

换三张完成后、庄家首次出牌前，四家各自选择万、筒、条中的一个缺门。本轮选定后不能修改；选择期间仅公开各家是否完成，全部完成后公开缺门并开始出牌。

定缺倒计时为 10 秒，由房主服务器统一推进；四家提前选完立即开始。超时者自动选择手牌（含庄家摸牌）中数量最少的花色，同数按万、筒、条顺序选择。其他玩法不进入定缺阶段，每个新四川轮次重新定缺。

持有缺门牌时必须优先打出缺门牌，后续摸到缺门牌同样适用；不能碰、明杠、暗杠、补杠缺门牌，也不能带缺门牌胡牌。客户端禁用不合法出牌，服务端再次校验。

规则依据：[游戏茶苑四川麻将定缺说明](https://www.gametea.com/ask/201809/7375.html)。10 秒时长与超时选择策略为本项目约定。

每次进入出牌阶段开始 15 秒倒计时，房主服务器统一判断超时并广播自动出牌结果。有缺门牌时优先打缺门；否则打本次摸到的牌。碰牌后没有摸牌时，从合法手牌中选择一张。碰杠胡响应阶段不使用出牌倒计时。定缺后手牌按缺门在最右侧排列，后续摸牌和整理同样保持这一顺序。
